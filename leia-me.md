# Site Soma — GET e POST

Atividade de Desenvolvimento de Software em Nuvem e
Ambientes de Desenvolvimento de Software.

Servidor desenvolvido com Node.js e Express.

## Executar

npm install
node servidor.js

Acessar http://localhost:3000 no navegador.

## GET /

Retorna um formulário para inserir dois números.

![Acesso GET bem-sucedido]

## POST /soma

Recebe os números enviados pelo formulário, calcula a soma
e retorna o resultado. O teste foi feito com 10 e 5,
obtendo o resultado 15.

![Acesso POST bem-sucedido]
